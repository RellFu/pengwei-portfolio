# Portfolio repository instructions

## Visitor-facing copy

- Do not use the em dash character (`—`) anywhere in visitor-facing website copy. The user considers it an obvious AI-writing signal.
- Rewrite the sentence instead. Prefer a period, comma, colon, parentheses, or a clean sentence break according to meaning.
- Apply this rule to headings, descriptions, labels, captions, buttons, metadata, and simulated product content.
